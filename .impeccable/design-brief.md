# BeatSmith Design Brief — 首页 + 登录 + 5 页面体系

## 1. Feature Summary

BeatSmith 的入口体验和核心页面体系。首页是沉浸式全屏着陆页，登录/注册是浮动表单 + 动态背景。另外包含歌曲库、排行榜、个人档案三个功能页面。目标是让用户打开网页的瞬间感受到「这不是普通工具，是节奏游戏」。

## 2. Primary User Action

**首页**：看到标题和动态背景后，点击 CTA 进入游戏
**登录**：在动态背景前完成注册/登录
**歌曲库**：浏览和选择歌曲开始游玩
**排行榜**：查看自己和他人的排名
**个人档案**：查看完整游玩数据和历史

## 3. Design Direction

| 维度 | 决定 |
|------|------|
| 色彩策略 | **Drenched** — 入口页面是品牌表达主场，产品内部回归 Committed |
| 主题场景 | 「午夜街机厅，霓虹灯管在黑暗中脉动，屏幕上跳动着音频波形，空气中弥漫着电子音乐的节奏感」 |
| 锚点参考 | osu! 官网沉浸感、Raycast 极简启动、Spotify Wrapped 数据冲击力 |

## 4. 页面详细设计

### 4.1 首页（/）

**布局**：全屏 Canvas 动态背景 + 居中内容

**视觉层次**：
1. 动态粒子/波形背景（Canvas，实时渲染）
2. 巨型标题「BeatSmith」— 霓虹发光，OKLCH primary 色
3. 中文副标题「节拍铁匠」— muted 色，较小
4. CTA 按钮「开始锻造 ⚒️」— 霓虹边框，hover 时发光增强

**动态效果**：
- 粒子系统：圆点 + 连线，随鼠标移动有微妙跟随
- 标题：微妙的呼吸灯效果（opacity 0.9-1.0 缓慢循环）
- CTA：hover 时霓虹光效扩散（box-shadow 增强）
- 背景有节奏感的几何线条在缓慢流动

**交互**：
- 鼠标移动 → 粒子有跟随效果
- CTA hover → 霓虹光效增强
- CTA click → 跳转到歌曲库或登录

**状态**：
- 默认：粒子背景 + 标题 + CTA
- 已登录：CTA 变为「进入工作台」
- 加载中：粒子仍在动画（永不空白）

### 4.2 登录/注册页（/login）

**布局**：全屏 Canvas 动态背景（延续首页风格）+ 居中浮动卡片

**浮动卡片设计**：
- 背景：`--surface` 色，`border-radius: --radius-lg`
- 边框：1px `--border`，focus 时变为 `--primary` 霓虹色
- 宽度：400px max，响应式缩放
- 内边距：32px

**登录表单**：
```
┌─────────────────────────┐
│   ⚒️ BeatSmith          │  ← logo + 品牌名
│                         │
│   用户名                │  ← input，focus 时霓虹边框
│   ┌───────────────────┐ │
│   │                   │ │
│   └───────────────────┘ │
│                         │
│   密码                  │
│   ┌───────────────────┐ │
│   │                   │ │
│   └───────────────────┘ │
│                         │
│   ┌───────────────────┐ │
│   │      登  录       │ │  ← primary 按钮，hover 发光
│   └───────────────────┘ │
│                         │
│   没有账号？立即注册     │  ← accent 色链接
└─────────────────────────┘
```

**切换动画**：
- 登录 ↔ 注册在同一卡片内切换
- 用 slide 动画（左/右滑动），不跳转页面
- 切换时表单内容淡出 → 新内容淡入

**注册表单**：
- 用户名、昵称、密码、确认密码
- 密码不匹配时实时提示（霓虹红）
- 用户名已存在时提交后提示

**交互**：
- 输入框 focus → 霓虹边框亮起（primary 色 glow）
- 提交按钮 → 脉冲动画
- 错误 → 输入框边框变 error 色 + 下方提示文字

### 4.3 歌曲库页（/songs）

**布局**：顶部导航 + 内容区

**唱片店风格**：
- 歌曲以卡片形式展示，每行 3-4 个
- 卡片包含：歌曲封面（默认用渐变色占位）、歌名、艺术家、BPM、游玩次数
- 卡片边框：霓虹色，hover 时发光增强
- 热门歌曲区域在顶部，全部歌曲在下方

**卡片设计**：
```
┌─────────────────┐
│  ┌─────────────┐│
│  │   渐变封面   ││  ← 16:9 比例，霓虹渐变占位
│  │             ││
│  └─────────────┘│
│  歌曲名称       │  ← text-lg, ink 色
│  艺术家名       │  ← text-sm, muted 色
│  ♫ 128 BPM     │  ← text-xs, muted 色
│  ▶ 42 次游玩    │  ← text-xs, accent 色
└─────────────────┘
```

**交互**：
- 卡片 hover → 边框霓虹发光 + 微微上浮（translateY -2px）
- 卡片 click → 跳转到谱面详情页
- 无限滚动或分页加载

### 4.4 排行榜页（/leaderboard）

**布局**：顶部 Tab 切换 + 排行列表

**Tab 切换**：
- 「全局总分」和「单曲排行」两个 Tab
- Tab 选中时底部有 primary 色指示条
- 单曲排行 Tab 选中后，下方出现歌曲选择器

**排行列表**：
```
┌──────────────────────────────────────────┐
│  #   玩家      总分        评级分布       │
├──────────────────────────────────────────┤
│  🥇  玩家A    2,500,000   SSS×12 SS×8   │
│  🥈  玩家B    2,100,000   SS×15  S×20   │
│  🥉  玩家C    1,800,000   S×25   A×10   │
│  4   玩家D    1,500,000   S×18   A×15   │
│  ...                                     │
└──────────────────────────────────────────┘
```

**当前用户高亮**：
- 如果当前用户在排行中，该行有 primary 色背景高亮
- 显示「你的排名: #X」

### 4.5 个人档案页（/profile/:id）

**布局**：顶部用户信息 + 评级分布 + 游玩记录

**用户信息区**：
```
┌─────────────────────────────────────┐
│  [头像]   玩家昵称                   │
│           加入于 2026-01-15         │
│           总分: 1,250,000           │
│           游玩次数: 42              │
│           最高连击: 856             │
└─────────────────────────────────────┘
```

**评级分布**：
```
┌─────┬─────┬─────┬─────┬─────┐
│ SSS │ SS  │  S  │  A  │  B  │
│  5  │ 12  │ 15  │  8  │  2  │
│金✨ │ 蓝  │ 绿  │ 橙  │ 灰  │
└─────┴─────┴─────┴─────┴─────┘
```
- 每个评级格子有对应颜色背景
- 数字居中显示

**游玩记录列表**：
- 按时间倒序
- 每行显示：歌曲名、评级、准确率、分数、游玩时间
- 点击跳转到谱面详情

## 5. Key States

| 页面 | 默认 | 加载中 | 错误 | 空状态 |
|------|------|--------|------|--------|
| 首页 | 粒子+标题+CTA | 粒子仍在动 | 无 | 无 |
| 登录 | 浮动表单+背景 | 提交按钮 loading | 输入错误高亮 | 无 |
| 歌曲库 | 卡片墙 | skeleton 卡片 | 加载失败提示 | 「还没有歌曲，去上传一首吧」 |
| 排行榜 | 排行列表 | skeleton 行 | 加载失败提示 | 「还没有人玩过，成为第一个吧」 |
| 个人档案 | 完整数据 | skeleton | 用户不存在 | 「还没有游玩记录」 |

## 6. Interaction Model

- **首页**：鼠标移动→粒子跟随；CTA hover→霓虹增强；CTA click→导航
- **登录**：输入框 focus→霓虹边框；切换→滑动动画；提交→脉冲
- **歌曲库**：卡片 hover→发光+上浮；卡片 click→导航
- **排行榜**：Tab 切换→内容切换动画；排行行 hover→微妙高亮
- **个人档案**：评级格子 hover→放大效果；记录行 hover→背景变化

## 7. Content Requirements

**文案**：
- 首页标题：「BeatSmith」
- 首页副标题：「节拍铁匠」
- CTA：「开始锻造 ⚒️」（未登录）/「进入工作台」（已登录）
- 登录按钮：「登录」
- 注册按钮：「注册」
- 切换链接：「没有账号？立即注册」/「已有账号？立即登录」
- 空状态：「还没有歌曲，去上传一首吧」
- 错误：「用户名已存在」「密码不匹配」「用户名或密码错误」

**图标**：Lucide icons，1.5px stroke

## 9. Open Questions

- 粒子系统的具体形态：圆点+连线 vs 纯圆点 vs 几何线条 → 推荐圆点+连线（经典且性能好）
- 歌曲封面：默认用 OKLCH 渐变色占位（primary→accent 渐变）
- 背景是否需要音频响应 → 首页暂不需要（没有加载音频），登录页也不需要
